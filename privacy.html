개인정보처리방침

시행일: 2026년 10월 5일

1. 앱의 성격과 목적

HermesGoogleApi는 앱 소유자가 본인의 Google Calendar 일정과 Google Tasks 할 일을 확인하고 일일 요약을 받기 위해 운영하는 개인용 자동화입니다. 일반 사용자를 대상으로 계정이나 서비스를 제공하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Google Calendar의 캘린더 목록, 일정 제목·시간·설명 등 일정 요약에 필요한 정보
  • 대한민국 공휴일 캘린더의 일정 정보
  • Google Tasks 기본 목록의 할 일 제목, 상태 및 기한
  • Google API 인증에 필요한 OAuth 액세스 토큰과 갱신 토큰

3. 데이터 사용 방법

Google 사용자 데이터는 앱 소유자의 당일 일정과 할 일을 조회하여 읽기 쉬운 개인용 요약을 생성하는 데만 사용됩니다. 광고, 사용자 추적, 신용평가, 판매 또는 제3자 프로파일링에 사용하지 않습니다.

4. 저장과 보관

OAuth 토큰은 앱 소유자가 관리하는 개인 NAS에 저장되며 공개 GitHub 저장소나 이 웹사이트에 저장되지 않습니다. 조회한 일정과 할 일은 요약 생성 과정에서 처리됩니다. 생성된 요약 및 운영 로그는 개인 NAS의 Hermes Agent 기록에 남을 수 있으며 앱 소유자가 직접 관리하고 삭제합니다.

5. 데이터 공유

생성된 일정 요약은 앱 소유자가 설정한 개인 Telegram 대화로 전달될 수 있습니다. 이는 사용자가 요청한 알림 기능을 수행하기 위한 것이며, 그 외의 제3자에게 Google 사용자 데이터를 판매하거나 임의로 제공하지 않습니다.

6. 보안

인증 파일은 개인 NAS에서 제한된 파일 권한으로 관리됩니다. 저장소에는 클라이언트 보안 비밀, OAuth 토큰 또는 Google 사용자 데이터를 게시하지 않습니다.

7. 접근 취소 및 삭제

앱 소유자는 Google 계정의 보안 설정에서 언제든지 HermesGoogleApi의 접근 권한을 취소할 수 있습니다. 로컬에 저장된 OAuth 토큰, 생성된 보고서 및 로그는 개인 NAS에서 직접 삭제할 수 있습니다.

8. 정책 변경

사용하는 Google API, 데이터 처리 방식 또는 알림 전달 방식이 변경되면 이 문서를 갱신하고 시행일을 변경합니다.

9. 문의

문의는 GitHub 저장소의 Issues를 이용할 수 있습니다.

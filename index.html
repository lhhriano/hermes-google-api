Riano Automation Hub

개인용 Hermes Agent에서 Google Calendar와 Google Tasks를 이용해 매일의 일정과 할 일을 요약하는 비공개 자동화입니다.

개인정보처리방침 이용조건

사용 목적

본인 Google 계정의 당일 일정, 대한민국 공휴일 및 기본 할 일 목록을 읽어 개인용 일일 요약을 생성합니다.

운영 방식

자동화는 앱 소유자가 관리하는 개인 NAS의 자체 호스팅 Hermes Agent에서 실행됩니다. 이 웹사이트는 OAuth 안내용 정적 페이지이며 Google 데이터를 수집하지 않습니다.

공개 범위

이 앱은 일반 사용자에게 제공되는 서비스가 아니며 앱 소유자 개인의 생산성 자동화만을 위해 사용됩니다.

사용하는 Google 서비스

  • Google Calendar API — 일정 및 공휴일 조회
  • Google Tasks API — 기본 할 일 목록 조회

필요에 따라 지도 등 다른 Google API 기능이 추가될 수 있습니다. 앱은 필요한 최소 범위의 권한만 요청하며 광고·프로파일링·데이터 판매에 사용하지 않습니다.

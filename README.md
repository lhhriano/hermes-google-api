# HermesGoogleApi

Personal OAuth information site for a self-hosted Hermes Agent automation using Google Calendar and Google Tasks.

## Pages

- Home: `index.html`
- Privacy policy: `privacy.html`
- Terms of use: `terms.html`

This repository contains only the public static website. OAuth client secrets, access tokens, refresh tokens, calendar data, task data, reports, and local configuration must never be committed.
